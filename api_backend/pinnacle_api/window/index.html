Module pinnacle_api::window

source ·
Expand description

Window management.

This module provides Window, which allows you to get WindowHandles and move and resize windows using the mouse.

WindowHandles allow you to do things like resize and move windows, toggle them between floating and tiled, close them, and more.

This module also allows you to set window rules; see the rules module for more information.
